# VLA 시연 수집 계획

> 브랜치 `kica927/smolVLA-version`. 하드웨어 접근은 **2026-09-08 에 끝납니다.**
> 그 뒤로는 여기서 찍은 것만 남습니다.

---

## 0. 무엇을 시연하는가 — 팔만입니다

정책은 **팔만 움직입니다.** 정책 노드는 베이스 방향을 항상 0으로 보냅니다
(`smolvla_policy_node`). 주행은 베이스라인 미션의 일이고, 그쪽은 이미
동작합니다.

그래서 한 에피소드는 이렇습니다.

```
차량은 이미 물체 앞에 서 있다 (사람이 세우거나 베이스라인이 세운다)
  → 사람이 리더 암으로 집는다
  → 바구니 위로 옮긴다
  → 놓는다
  → IDLE 로 되돌린다
```

**주행을 넣지 마세요.** 정책이 배울 수 없는 것을 데이터에 넣으면 그 구간의
액션이 "아무것도 안 함"으로 학습됩니다.

## 1. 몇 개를 찍는가

| | |
|---|---|
| 클래스 | **1개부터** (rook 권장 — 파지 자세가 가장 잘 검증돼 있습니다) |
| 에피소드 | **54개** (아래 격자 9칸 × 6회) |
| 한 에피소드 | 20~40초 |
| 예상 소요 | 준비 30초 + 시연 30초 + 정리 20초 ≈ **2시간** |

### 왜 1클래스인가

6클래스를 같은 밀도로 찍으면 324 에피소드입니다. 남은 9일에 베이스라인
작업까지 있으니 불가능합니다. **하나를 제대로 하는 편이 여섯을 얕게 하는
것보다 낫습니다** — 되면 그때 두 번째 클래스를 얹습니다.

### 54라는 숫자

LeRobot 의 SO-101 튜토리얼이 단일 pick-place 과제에 쓰는 규모(50 안팎)에
격자를 맞춘 값입니다. **제가 실측한 수가 아닙니다.** 적으면 위치 일반화가
안 되고, 많으면 시간이 모자랍니다.

## 2. 무엇을 바꾸는가 — 격자

차량은 고정합니다. **물체 위치만 바꿉니다.**

|  | 좌 −3cm | 중앙 | 우 +3cm |
|---|---|---|---|
| **앞 17cm** | 6회 | 6회 | 6회 |
| **앞 19cm** | 6회 | 6회 | 6회 |
| **앞 21cm** | 6회 | 6회 | 6회 |

19cm 중앙이 GRASP 의 설계 전제(물체 중심이 차체 앞 19cm, 정중앙)이고,
나머지 8칸이 그 전제가 흔들렸을 때입니다.

**바꾸지 않는 것:** 조명 · 바구니 위치 · 차량 자세 · 시작 팔 자세(IDLE).
한 번에 한 축만 바꿔야 무엇이 효과가 있었는지 알 수 있습니다.

### 평가용으로 두 칸을 남깁니다

`앞 17cm 좌 −3cm` 와 `앞 21cm 우 +3cm` — **대각선 두 칸은 학습에서
빼세요.** 정책이 위치를 일반화하는지 볼 유일한 방법입니다. 전부 학습에
넣으면 "외웠는지 배웠는지" 구분할 수 없습니다.

학습 42개 · 평가 12개가 됩니다.

## 3. 실패한 시연은 버립니다

행동 복제는 **보여준 것을 그대로 배웁니다.** 놓친 파지를 넣으면 놓치는 것을
배웁니다.

- 집다가 놓쳤다 → 그 에피소드는 버립니다(추종을 끄고 다시)
- 두 번 시도해서 성공했다 → **버립니다.** 재시도는 베이스라인의 일입니다
- 살짝 어색했지만 성공했다 → 넣습니다

`INDEX.md` 에 버린 것도 적으세요. 나중에 "왜 42개인가"를 설명할 수 있어야
합니다.

## 4. 작업 규칙

파이 접속과 컨테이너 진입:

```
ssh pi@raspberrypi.local
cd ~/docker && ./exec_shell.sh
```

**컨테이너 셸은 zsh 입니다.** `setup.bash` 가 아니라 `setup.zsh` 입니다.

```
export ROS_DOMAIN_ID=21
source /opt/ros/humble/setup.zsh
source /ros2_ws/install/setup.zsh
source /home/ubuntu/third_party_ros2/third_party_ws/install/setup.zsh
```

배포·재시작 뒤에는 `perception_node` 가 떠 있는지 항상 확인합니다.

### ⚠️ 캘리브레이션을 먼저 정하세요

VLA 수집은 **LeRobot 캘리브레이션**으로 돕니다. 베이스라인 미션을 돌린
직후라면 팔이 교시 캘리브레이션으로 되돌려져 있습니다.

```
python3 tools/arm/restore_taught_offsets.py
```

"일치합니다"가 나오면 **베이스라인 상태**입니다. 그대로 VLA 를 찍으면
베이스라인 자세로 학습됩니다 — 의도한 게 아니면 LeRobot 캘리브레이션을
먼저 하세요. 아래 preflight 가 이것도 봅니다.

## 5. 접속하자마자 — preflight

```
bash /grippers/tools/vla/preflight.sh
```

**아무것도 바꾸지 않습니다.** 노드를 죽이지도, `/cmd_vel` 을 발행하지도,
서보에 쓰지도 않습니다.

여덟 가지를 봅니다.

| | 무엇 | XX 면 |
|---|---|---|
| 1 | `ROS_DOMAIN_ID=21` · ros2 | 막힘 |
| 2 | 브랜치와 작업트리 | 확인만 |
| 3 | **배포된 코드가 맥에서 검증한 그 코드인가** | 막힘 |
| 4 | 팔이 어느 캘리브레이션인가 | 확인만 |
| 5 | 그리퍼캠 장치·노드·**압축 토픽** | 막힘 |
| 6 | `/teleop/follower_present` | 막힘 |
| 7 | 디스크와 **실측 대역폭으로 몇 분** | 여유 부족이면 막힘 |
| 8 | lerobot · cv2 · rosbag2_py | 확인만 |

3번이 핵심입니다. 파일을 옮기다 반쪽만 올라가거나 컨테이너가 옛 사본을
들고 있는 일이 실제로 있었습니다. **수집은 되돌릴 수 없는 시간이라,
의심스러운 코드로 시작하지 않습니다.**

7번은 제가 추측한 숫자가 아니라 `ros2 topic bw` 로 **그 자리에서 잽니다.**

## 6. 순서

### ① 그리퍼캠을 먼저 띄웁니다

```
ros2 run grippers_perception gripper_cam_publisher_node
```

`perception_node` 와 동시에 못 뜹니다 — 같은 `/dev/gripper_cam` 을 독점으로
엽니다.

### ② preflight 를 다시 돌립니다

이번엔 압축 토픽이 보여야 합니다.

### ③ 텔레옵을 켭니다

노트북에서:

```
cd ~/grippers-teleop && ./teleop.sh
```

### ④ preflight 를 한 번 더

`/teleop/follower_present` 가 나와야 합니다. **이게 없으면 찍어도
학습 데이터가 안 됩니다.**

### ⑤ 30초 시험 — 첫날 반드시

한 에피소드만 찍고 바로 변환기로 확인합니다.

```
bash /grippers/tools/teleop/record_demo.sh --with-camera
```

`f` 로 추종을 켜고 한 번 집었다 놓고, `f` 로 끄고, Ctrl-C.

```
python3 /grippers/tools/vla/bag_to_lerobot.py /grippers/recordings/demo_XXXX --dry-run
```

에피소드 1개와 프레임 수가 나오면 성공입니다. **0개면 여기서 멈추고
원인을 찾으세요** — 본 수집을 하고 나서 알면 되돌릴 수 없습니다.

### ⑥ 본 수집

격자 칸마다 6회. 칸을 바꿀 때마다 `INDEX.md` 에 적습니다.

### ⑦ 그날 안에 맥으로 가져옵니다

파이의 `/tmp` 는 컨테이너를 다시 만들면 사라집니다. **9월 7일에 한 번 더**
최종본을 가져오세요.

## 7. 지시 문장은 하나로 고정합니다

SmolVLA 는 이 문장을 언어 입력으로 읽습니다. **모든 에피소드가 같은
문장이어야 합니다.**

```
--task "체스말을 집어 바구니에 넣는다"
```

에피소드마다 다르게 쓰면 정책이 문장과 동작을 잘못 엮습니다.

## 9. 확인하지 못한 것

- 한 에피소드의 실제 용량과 소요 시간. preflight 7번이 그 자리에서 잽니다
- 54개가 충분한지. LeRobot 튜토리얼 규모에 맞춘 것이고 실측이 아닙니다

- `--state-period` 1/15초가 50Hz 텔레옵의 직렬 버스 예산에 드는지.
  **텔레옵이 버벅이면 이것부터 의심하세요**
